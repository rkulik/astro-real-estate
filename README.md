# Astro Real Estate

Astro Real Estate is a modern, high-performance real estate website built with Astro and Storyblok. It features a clean, minimalist design optimized for property listings and real estate marketing. The website includes a responsive layout, fast image loading, and SEO-friendly structure.

## Technologies

- [Astro](https://astro.build/) - Modern static site builder with exceptional performance
- [Storyblok](https://www.storyblok.com/) - Headless CMS for managing content
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework for rapid UI development
- [TypeScript](https://www.typescriptlang.org/) - Type-safe JavaScript for better development
